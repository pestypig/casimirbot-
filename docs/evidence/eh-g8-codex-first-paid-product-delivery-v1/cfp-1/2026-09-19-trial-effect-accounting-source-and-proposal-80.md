Proposed CFP-1 unit for the **one-block mine candidate only**: one effect is one uniquely identified, owner-granted, guest-requested native removal of the exact admitted block. One successful request under those bounds can settle **one** effect, never more; a replay or observation re-read settles zero additional effects. The fresh observation is a proposed extra acceptance check, not a claim that the current broker already performs it for billing.

Proposed reserve/settle rule for CFP-3 review:

| State | Trial-cap treatment | Required evidence/behavior |
| --- | --- | --- |
| Denied before effect admission | No successful effect; no lasting reservation | Typed denial; no connector dispatch. |
| Admitted new request | Reserve one capacity slot atomically for the sponsoring identity before native dispatch | Reject if settled successes plus outstanding reservations would exceed the frozen cap. Bind the slot to sponsor, room, action request, idempotency key and term revision. |

| Effect possible, response lost, late, failed or conflicting | Keep the capacity slot unavailable as **pending reconciliation**, while showing it separately from consumed successes | No automatic replay or fresh grant for the same target. Settle success only with verified effect evidence; release only with proven no-effect evidence. Escalate unresolved cases through a bounded operator/support process without converting uncertainty into a charge or a free slot. |
| Trial expiry, cancellation, revoke or host handoff | Stop new admissions immediately under the applicable fence | Preserve the old sponsor's settlement history and unresolved reservations. A successor's eligibility never transfers the old sponsor's consumed or pending quota or the program grant. |

The guarantee sought is `settled_successes + outstanding_reservations <= final_cap` for each trial sponsor throughout concurrency, retry, room recreation, reinstall and same-identity account return. This is a **capacity** rule, not a claim that an unverified attempt consumed a successful effect.
