Provider check: [Auth0 step-up guidance](https://auth0.com/docs/secure/multi-factor-authentication/step-up-authentication) documents MFA challenges for sensitive resources; [WebAuthn MFA](https://auth0.com/docs/secure/multi-factor-authentication/webauthn-as-mfa) is a candidate factor, subject to the actual tenant configuration; [Auth0's federated reauthentication warning](https://auth0.com/docs/authenticate/login/max-age-reauthentication) says an upstream exchange may update Auth0 `auth_time` without a new Google authentication. A public Google-only journey would need a separately evidenced **operation-time Auth0 factor challenge**, linked subject, initial factor enrollment and factor-loss recovery. Provider feature availability, plan cost and configured-client behavior were not checked here.

Targeted deterministic verification: `npx vitest run server/routes/__tests__/desktop-auth0-step-up.test.ts server/routes/__tests__/desktop-auth0-account-link.test.ts server/services/helix-account/__tests__/auth0-step-up.test.ts server/services/helix-account/__tests__/auth0-step-up-receipt-store.test.ts server/services/helix-account/__tests__/auth0-native-account-link.test.ts server/services/helix-account/__tests__/agent-account-link-store.test.ts --pool=forks` returned **six files, 45 tests passed**. These tests establish existing developer/native component behavior, not a new public account route, live tenant MFA or Google-only installed acceptance.

**Decision:** Auth0 linked MFA is a first qualification candidate for D02, not a selected customer identity requirement. The CFP-2 experiment must exercise an ordinary `user` with only a Google-owned CasimirBot profile, stale Google SSO, explicit Auth0 link and factor challenge, same-profile P1 enrollment and recovery, and the denials named in the [feasibility packet](../../../work-packets/eh-g8-cfp1-google-p1-fresh-auth-feasibility-v1.md). Account/security review must accept the initial link/factor-enrollment trust and recovery rule; commerce must include tenant/factor cost in D07. If unavailable or too burdensome, compare a first-party authenticator under the same proof criteria. This does not close D02, D07, D11, D12 or CFP-1.
