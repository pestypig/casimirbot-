# CFP-1 finite room-activity assay direction — 2026-09-20

Program gate: G8 — Environment-harness release evaluation. CFP-1 remains active (`specified`); CFP-2/3 remain blocked. This is a provisional first-cohort **cost and usability assay direction**, not an owner-selected numeric idle interval, room-hour allowance, PBT cap, price, implemented control, financial-review return or installed customer capability.

The [open-browser source audit](2026-09-20-cfp1-open-browser-room-cost-source-audit-212.md) found that the current **experimental** room continues database-backed refresh and presence while its dialog is closed. [Replit's current publishing/database billing guide](https://docs.replit.com/billing/about-usage-based-billing) says a production database remains active for five minutes after its last request. A seven-day no-card trial with a continuously successful open tab is therefore a material adverse cost case. The operator-private sensitivity remains in `~/.codex/private-evidence/cfp1/2026-09-20-d07-open-browser-db-active-screen.md` (SHA-256 `3CA63622A7AED585079E7AE8DB3592DFFBFB0DD068B2C1E33861312C91A02FD3`); no account rate or derived amount is copied here. This is not measured cost of the unbuilt first-party no-model guest room or a per-sponsor marginal charge.

The [guest-ingress contract](../../../work-packets/eh-g8-cfp1-hosted-guest-request-ingress-v1.md), [D07 assay](../../../work-packets/eh-g8-cfp1-d07-provider-unit-allocation-and-assay-v1.md) and [pilot assay](../../../work-packets/eh-g8-cfp1-hosted-pilot-price-and-capacity-assay-v1.md) now prefer finite, explicitly renewed room activity for the first cost/usefulness test. Passive browser visibility, heartbeat and polling do not renew an active lease. After a still-unselected idle boundary, routine database-backed presence/refresh work stops and the page shows suspension. An intentional return rechecks the current account/session, sponsor term/capacity, membership and program visibility, then reserves a new finite lease. Exact action grant/revision checks occur separately before an effect; a grant is not required merely to inspect a permitted room or idempotent queued status. Owner stop/revoke and safe native release remain reachable through suspension or PBT exhaustion. The trial's seven-day clock, ten verified-effect target and sponsor PBT do not reset on suspension.

This narrows the **next assay design**, not the final customer offer. D07 still must measure or source-bound foreground, background, unattended, suspended and return workloads on the selected first-party route, including requests, compute, database active-time union/tails, egress, fixed/support and cohort effects. It must select a numeric idle/lease policy and PBT/resource bounds only after testing whether ten rights-cleared effects remain useful across seven days. If finite suspension fails that test, a separately costed and enforceable sustained-open alternative returns for owner review; the experimental cadence cannot silently become the paid route.
