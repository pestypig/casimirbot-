At 2026-09-19 19:21 UTC, in response to “For the seven-day hosted trial, if a host deletes their CasimirBot account and later signs in again with the same verified Google/Auth0 identity, should the used trial remain used? This sets the one-time trial policy; the retention period and privacy implementation will still receive a separate review,” the owner answered **“Yes, a used trial stays used (Recommended).”** This selects a return rule for the **same verified sign-in identity**. Deletion does not reset that identity's consumed seven-day hosted trial, and account reactivation, a new session, device, room or provider callback cannot restart its clock.

The implementation contract must distinguish a provider issuer/subject from an email address. A matching email alone is not evidence that two accounts share the trial history. An explicitly linked second provider should be evaluated against the same sponsor's consumed-trial state, but the exact deleted-account/relink recovery protocol and namespace treatment remain to freeze. No old room membership, program grant, consent, subscription, node or effect authority is restored merely because the sign-in identity is recognized. Free personal access remains independently authorized.

This owner answer **does not** select the trial start trigger, eligible benefit set, outage clock, in-flight expiry, paid-conversion flow, record design, retention period, deletion/export notice, or privacy/legal basis for keeping the minimum anti-reuse evidence. Those require account/privacy and qualified review before CFP-3 implementation. The existing soft-delete/upsert and sandbox credit ledger do not enforce this policy. Test same-subject deletion and return, a previously linked provider, same-email distinct subjects, concurrent first starts, repeat starts, expiry, and stale-grant rejection. A trial start still collects no card and causes no charge.

**Stage effect:** O-05's one-time return question is partially resolved; O-05/O-07 are not closed. CFP-1 remains active (specification), and CFP-2/3 remain blocked under the G8 ledger. This decision grants no production trial or paid entitlement.
