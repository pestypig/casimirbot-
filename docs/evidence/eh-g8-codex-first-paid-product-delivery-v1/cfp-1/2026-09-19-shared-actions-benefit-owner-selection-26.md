# CFP-1 first hosted benefit selection — 2026-09-19

Status: dated capture of a product-owner selection for O-02. The [CFP-1 contract](../../../work-packets/eh-g8-cfp1-product-rights-and-offer-contract-v1.md) remains the working specification and the [environment work program](../../../helix-environment-harness-work-program-v1.md) retains stage authority. No runtime, billing, public claim, rights permission or release state changed.

Asked: “For the first paid hosted offer, should the promised benefit include guests using owner-granted program actions once each connector and its commercial rights pass review, or launch room coordination and read-only sharing first?”

The owner selected **“Include rights-cleared shared actions (recommended).”** The first paid hosted benefit is therefore authenticated room coordination **plus a selected set of accepted, rights-cleared shared-program actions** requested by invited guests under each program owner's exact grant. Every advertised action in that set must pass; one useful action is the minimum launch demonstration, not a cap on the eventual supported set. A coordination/read-only-only paid launch is not the selected O-02 outcome. This selects product scope, not an existing action path, a specific Minecraft verb, a whole MCP catalog, a rights classification or permission to charge.

The action-inclusive launch must name each selected program/connector, capability ID and version, actor, target, effect limits, owner grant, consent, active host paid eligibility, guest membership, native lease and measured postcondition. It must pass positive and negative installed acceptance with a separately authenticated host and guest on the declared artifact/service. The owner's O-02 answer concerned the **paid offer**; it did not decide whether the seven-day hosted trial includes shared actions. That trial benefit remains a separate O-05 decision. Payment and room membership alone never confer program authority; the owner's independently authorized personal operations remain free. Room-only reads, stop/revoke and post-expiry recovery need their own operation-specific rules.

R-MC-01 remains open for any selected Minecraft shared action. The existing [Minecraft rights-review brief](2026-09-19-selected-hosted-minecraft-rights-review-23.md) compared read-only and action variants because O-02 was then unselected; this later decision chooses the action-inclusive variant for the first paid offer **only if** its connector and actual monetization relationship receive a qualified disposition. If no action candidate passes technical and rights review, the action-inclusive first paid offer is not ready; do not silently substitute an unreviewed Minecraft action or relabel a read-only room as fulfilling O-02. A separately rights-cleared non-Minecraft action may qualify if the product owner selects its exact capability and acceptance.

O-02 still needs an operation-by-context release register and accepted action/room versions before final freeze. O-03 price/Stripe mapping, O-04 limits, remaining O-05 trial/conversion/outage, O-06 cancellation/refund and O-07 retention/support remain open.
