# CFP-1 hosted browser identity source boundary — 2026-09-20

Source HEAD inspected: `cc5a7a4c1ac956606aea756f59e6fcb0324a9f93`; shared dirty worktree. Read-only source inspection; no public/installed account acceptance.

- `server/services/helix-account/account-session-store.ts` creates a temporary `provider: "guest"` account and 24-hour session when Shared Live Rooms are enabled without another sign-in. Google/other web sign-in paths can insert a session with `expires_at: null`; the session lookup accepts a null expiry. `server/services/helix-account/session-cookie.ts` sets an HttpOnly, SameSite=Lax cookie with a seven-day default max age, but that browser limit does not impose an absolute server-session expiry. The [D02 session proposal](../../../work-packets/eh-g8-cfp1-public-session-and-client-grant-lifecycle-decision-v1.md) recommends a seven-day server maximum subject to account/security review.
- `server/routes/agi.realtime-room/http-context.ts` calls the current session trusted and identifies `profile.auth_mode === "guest"`, then admits feature-unlocked room accounts. The exported `requireSharedRoomHostingAllowed` helper is not a current caller-enforced restriction; `server/services/shared-live-room-control/service.ts` enforces the temporary-guest **create** restriction in `createRoom` when guest hosting is disabled. The current one-model room can still allow a temporary guest to **join** an invitation. That join is not the selected non-model paid room, but reusing its identity check unchanged would confuse a temporary guest session with the selected verified invited-account policy.
- `server/routes/google-auth.ts` verifies a direct Google credential and CSRF token before issuing a CasimirBot cookie. This proves a reusable sign-in path exists, not a final public account-session lifetime, paid membership or action grant.

Disposition: the [first-party hosted guest ingress](../../../work-packets/eh-g8-cfp1-hosted-guest-request-ingress-v1.md) must require a current verified provider-linked internal account on every selected create/invite/join/request/grant/read path; temporary `guest`/local-profile sessions cannot satisfy paid or trial eligibility. The proposed server-side absolute expiry, sign-out/revoke behavior, CSRF and return-to-current-membership cases require account/security review and later CFP-3/4 tests. This audit does not change current experimental Shared Live Room access or select D02's final duration. CFP-1 remains active (`specified`).
