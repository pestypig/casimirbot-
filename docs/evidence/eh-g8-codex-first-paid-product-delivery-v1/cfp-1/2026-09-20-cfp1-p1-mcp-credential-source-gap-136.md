[Official OpenAI MCP documentation](https://learn.chatgpt.com/docs/extend/mcp?surface=cli) supports Streamable HTTP and a local `http_headers_helper` command for locally connected HTTP MCP. Codex caches helper headers and, after a same-origin POST returns 401 or 403, refreshes them once only when the helper returns changed values. Explicit bearer tokens and stored OAuth credentials take precedence over a helper-provided `Authorization` header; an OAuth insufficient-scope 403 does not trigger helper refresh. The helper is not supported for a remote execution environment. This establishes a **client mechanism**, not a tested CasimirBot broker, grant, verified listener, dynamic-port recovery or installed ordinary-user catalog.

The P1 acceptance design must keep three identities separate: the user's external Codex account, their verified CasimirBot account, and an enrolled CasimirBot Windows installation. Neither Codex login nor Google email similarity grants local player authority.
