## Owner/reviewer return required to freeze this selector

The owner records one versioned planned component/profile matrix with `include`, `exclude`, `separately provision`, or `defer` per row, source/version or bounded inclusion rule, first customer claim, release channel and decision reference. The qualified reviewer returns a disposition and conditions for every selected component and for the *actual* paid action relationship, including notice/source-offer text, permission evidence where required, and excluded material. An unresolved rights row cannot be silently included. The release owner then turns each disposition into a positive/negative installed extraction test in CFP-3.SIGNING/DISTRIBUTION.

This sheet does not close CFP-1: the exact action/room/personal-operation register, O-03–07 and handoff/trial terms, component and Minecraft rights dispositions, planned inclusion choices and independent final contract review remain open. The [G8 ledger](../helix-environment-harness-work-program-v1.md) retains CFP-1 active and CFP-2/3 blocked.
