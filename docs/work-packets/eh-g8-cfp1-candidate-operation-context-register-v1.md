# CFP-1 candidate operation/context register v1

The [CFP-1 offer](eh-g8-cfp1-product-rights-and-offer-contract-v1.md) selects the principle: the **complete selected supported personal experience** is free, and a recurring hosted subscription may sponsor invited guests for selected shared-program actions under each program owner's grant. It does **not** select the specific operations below. The [104-name source triage](eh-g8-cfp1-mcp-offer-context-triage-v1.md) remains the whole-catalog worksheet. This register makes a first journey reviewable at the unit that actually matters: `(artifact, client surface, MCP/API operation, capability/version, context kind, actor, owner/subject/source, consent/grant, effect limit)`. Source HEAD inspected: `256554ca2637b2978a83616d9f9670069fdfd8c4`, with a shared dirty worktree. A source registration is not an installed `tools/list`, ordinary-user reachability or an accepted public claim.

`personal_environment` is the [selected target context architecture](../evidence/eh-g8-codex-first-paid-product-delivery-v1/cfp-1/2026-09-19-personal-context-architecture-decision-31.md), not current room behavior. The current full MCP handlers in `server/mcp/helix-mcp-server.ts` mostly require an enabled room and room ID; the coordination-only shadows deny with `full_mcp_transition_required`, and `helix_minecraft_situation_probe` has no shadow. The base `user` policy locks shared rooms and source ingress. The register's scope/ID observations are current source facts; all customer decisions and installed results remain `pending/not_run`.

## Freeze rule and remaining catalog disposition

Before CFP-1 closure, the product owner must select **every** advertised operation/context row, including non-Minecraft value, and mark all other source-level names as wizard-internal, shadow/unavailable, experimental/developer, or deferred in the [104-row worksheet](eh-g8-cfp1-mcp-offer-context-triage-v1.csv). For selected rows, add the release/client/connector manifest versions, exact full or narrow MCP surface, OAuth and account policy, first-party setup route, owner/subject/source/room identities, payer/guest and consent/grant rules, numeric effect/freshness/stop limits, rights decision reference, customer wording and positive/negative case IDs. No selection by silence or by a catalog descriptor. The selected personal set is free **in its entirety**; hosted expiry cannot remove independently authorized personal operations or stop/revoke.

CFP-1 freezes those contracts and claim tests.
