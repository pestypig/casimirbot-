## Required delegated-action contract

Current `action-broker.ts` rejects a non-owner requester when its participant ID differs from the paired player and rejects enqueue when the requester differs from the action request's participant ID. Current `authority-store.ts` requires a room owner to configure a player authority, then binds the active authority to the paired participant and allowed capability IDs. It has no independent guest requester, exact target/count envelope or one-use grant. The existing path must continue to reject unauthorized cross-participant calls.

Add a separate owner-issued grant for a selected program action, with server-derived identities for room, current sponsor revision, program owner profile, owner node/source/world/connector epoch, paired subject/participant, permitted requester profile/participant, capability ID/version, exact target and effect ceiling, creation/expiry, revocation revision and one-use nonce. The owner may authorize only their own verified program/subject even when another member pays for and controls the room; this must not grant general room management or source credential access. A host cannot issue the grant for a guest's program. A guest cannot self-grant by supplying owner fields. The grant is distinct from media consent, OAuth scope, room membership, existing player authority and hosted eligibility; all must be checked as applicable.

At effect admission, resolve the caller's verified account and participant separately from the target's paired participant. Accept the cross-participant branch only if the current room/sponsor is eligible for the selected paid operation, the requester is a current permitted member, the program owner's source and player authority are active, the exact signed/current grant matches the request and connector manifest, and the native effect envelope is no wider. Atomically consume the grant together with action enqueue/idempotency admission so concurrent/replayed requests cannot cause a second effect. Fence old sponsor, owner, member, source, player, connector-epoch and grant revisions on handoff/reconnect/revoke. Preserve the existing self-player branch and the free personal context without any hosted entitlement check. Failure returns a typed observation with the rejected invariant; no guessed substitute action or secret is exposed.
