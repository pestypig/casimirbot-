# CFP-1 hosted provider-spend and room seam v1

The [selected first offer](eh-g8-cfp1-product-rights-and-offer-contract-v1.md#selected-offer-free-personal-tools-paid-hosted-collaboration) charges for maintained hosted collaboration with an owner-granted shared-program action, while each person's supported external reasoning client/account remains separate. It excludes CasimirBot-funded inference, managed GPT Live and provider credits. The [source audit](../evidence/eh-g8-codex-first-paid-product-delivery-v1/cfp-1/2026-09-20-cfp1-hosted-model-spend-source-boundary-199.md) shows that the present Shared GPT Live Room is a two-member voice/model workflow; its SDP exchange can call OpenAI Realtime under a server or desktop-broker API key. Its existing `model_tokens_per_day` account quota is unrelated to the proposed hosted PBT allowance. The selected offer therefore needs its **own admitted room/coordination path** or a formally separated room mode whose entry, readiness and effects do not invoke or require that GPT Live runtime.

## Boundary to freeze for D12

For the first customer cohort, specify one hosted room kind and exact create, invite, join, inspect, grant-request, action-result, stop/revoke, leave, expiry and handoff operations. Room readiness for the selected collaboration mode may require verified identity, sponsor eligibility, membership, owner program consent and action grants as appropriate; it must not require microphone-to-model consent, GPT Live session creation, an OpenAI API key or a Codex subscription transfer. The [guest request ingress](eh-g8-cfp1-hosted-guest-request-ingress-v1.md) proposes a first-party bounded request that needs no guest model account; host or guest may also use their own separately supported reasoning client to call admitted tools. The platform must never assume either client's account can fund a server-side GPT Live SDP call. Preserve a distinct path and consent state for any later GPT Live/AI-assisted room. Reuse of current room tables, source bindings or control services is conditional on proving separation at the server boundary; merely changing a label, hiding a button or unlocking `shared_realtime_rooms` for `user` is insufficient.

The first-offer eligibility predicate is **verified account + active sponsored term/trial + operation-specific room membership/role + available PBT/resource capacity**. A shared-program effect additionally needs the program owner's exact current grant and native connector authority. Payment and room readiness alone create neither a model session nor an effect grant. The free personal MCP path and owner stop/revoke stay available without hosted capacity. A later managed voice/model mode requires a separate owner offer decision, provider terms and account/credential authority, processor/customer wording, measured provider usage and D07/D11 review; it cannot silently draw from the initial subscription's PBT or the host's Codex App subscription.

## Cost and implementation acceptance

Cost the selected non-model room's real identity, signaling/transport, database, storage, egress, action and support use in the [B/P/T assay](eh-g8-cfp1-d07-provider-unit-allocation-and-assay-v1.md). For this initial scope, expected CasimirBot-funded provider inference is **zero by route exclusion**, not an assumption that API calls are free. Any provider egress discovered in the selected ordinary-user path fails the no-funded-inference acceptance until it is removed or the offer is deliberately reselected and costed. The [internal PBT model](eh-g8-cfp1-hosted-resource-budget-token-contract-v1.md) accounts for platform resource costs; model input/output token quotas in `shared/helix-account-session.ts` do not enforce sponsor PBT.

The [current experimental-room refresh audit](../evidence/eh-g8-codex-first-paid-product-delivery-v1/cfp-1/2026-09-20-cfp1-open-browser-room-cost-source-audit-212.md) shows why excluding model calls is only one cost boundary. Its room/frame/presence timers continue at a lower cadence with the dialog closed and touch the database; copying that behavior into a seven-day no-model room without idle suspension or a costed sustained-open bound could exhaust hosted capacity through passive presence. The selected room must freeze foreground, unattended, suspended and return behavior independently of GPT Live; a hidden UI is not proof that polling or database work stopped. Do not choose push, polling or a heartbeat cadence as automatically cheaper without measuring provider compute, request and database-active units under the same billable deployment shape.

Before CFP-3 dispatch, freeze the room-kind/version and route map plus a fixture for each selected public operation. CFP-3 must prove that an ordinary `user` with an eligible trial/paid term can complete the selected two-account shared-action journey **with no OpenAI key, native credential broker or model session**, and that never-paid/expired users retain free personal tools. Instrument or stub provider transports so the selected journey asserts zero Realtime SDP/client-secret calls and zero CasimirBot-funded Ask/provider calls. Direct API/MCP/service attempts to start the excluded GPT Live path under the initial hosted entitlement must deny without provider egress; an authorized developer experiment remains governed by its separate existing policy. Test wrong sponsor, absent grant, expiry, revoke, restart and handoff across the same route. CFP-4 repeats the provider-call and cost-matrix checks on the selected signed artifact/service build. These are future acceptance fixtures, not tests passed by this document.

The existing G8 voice, federation and room obligations remain separately open. The first-offer path cannot claim that they are satisfied by a non-model room or by the current experimental GPT Live room. D07 still lacks a costed PBT/price choice; D11 qualified rights/privacy/financial returns and D12 integrated claim freeze remain open.
