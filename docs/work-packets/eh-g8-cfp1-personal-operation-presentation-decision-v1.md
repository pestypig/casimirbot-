# CFP-1 personal operation presentation decision v1

The selected product rule is that the **complete supported personal MCP experience is free**. It does not mean that every source registration is a first-release customer promise. The [105-name triage](eh-g8-cfp1-mcp-offer-context-triage-v1.md) has 23 `personal_candidate` and 15 `safety_or_status` names; those lanes are review priorities, not an accepted support list. The [2026-09-19 source recheck](../evidence/eh-g8-codex-first-paid-product-delivery-v1/cfp-1/2026-09-19-cfp1-current-mcp-source-catalog-recheck-68.md) found no name drift at its exact file hashes; the [later check](../evidence/eh-g8-codex-first-paid-product-delivery-v1/cfp-1/2026-09-20-cfp1-current-mcp-source-catalog-drift-132.md) adds one unqualified NAV name without installed catalog or ordinary-user acceptance. The [operation/context register](eh-g8-cfp1-candidate-operation-context-register-v1.md) proposes the first Minecraft journey and separately lists hosted rows. This packet clarifies how to decide **presentation and support** without shrinking the wider platform roadmap.

## Selection record and acceptance handoff

For each customer-visible or wizard-internal first-release row, CFP-1 must freeze `(artifact, client surface, operation/verb, capability and manifest version, personal context kind, actor, owner/source/subject, consent or grant, numeric/freshness/stop limits, rights disposition, customer wording)`. Record `selected`, `deferred`, `wizard-internal`, `developer/experimental` or `unavailable` **per context** in a new dated decision record after the owner's answer. A name reused in a sponsored room needs a distinct hosted row; no tool-name paywall is implied. Keep source-inventory and installed-acceptance fields separate. An installed `tools/list` and positive/negative ordinary-user actions later belong to CFP-2; signed/integrated repetition belongs to CFP-3/4. The [claims register](eh-g8-cfp1-claims-evidence-register-v1.md) still retains all twelve G8 obligations.

The owner selected a **narrower first customer-visible task and safety slice** in [selection 106](../evidence/eh-g8-codex-first-paid-product-delivery-v1/cfp-1/2026-09-20-cfp1-recommended-direction-owner-selection-106.md). The [context overlay](eh-g8-cfp1-first-customer-operation-target-overlay-v1.md) records that target separately from the unchanged 105-name source inventory and defers unlisted first-customer claims. The 23 personal candidates plus 15 safety/status names remain a triage slate, not a wholesale supported list. Each selected operation/context still needs rights, account and installed acceptance before a customer claim. CFP-1 remains active (`specified`) and CFP-2/3 blocked under the [work program](../helix-environment-harness-work-program-v1.md).
