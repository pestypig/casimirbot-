# CFP-1 selected-direction operation acceptance subcases v1

This is a **test design for the owner-selected first-customer target**, not a claim that the tools work for an ordinary installed user. It refines [FC-02–06](eh-g8-cfp1-first-customer-claim-freeze-worksheet-v1.md), [selection 106](../evidence/eh-g8-codex-first-paid-product-delivery-v1/cfp-1/2026-09-20-cfp1-recommended-direction-owner-selection-106.md), the [source-backed P/H register](eh-g8-cfp1-candidate-operation-context-register-v1.md) and the [first-customer context overlay](eh-g8-cfp1-first-customer-operation-target-overlay-v1.md). Only the free personal task slice and one conditional guest effect are selected as targets. The [first-cohort compatibility packet](eh-g8-cfp1-first-cohort-compatibility-target-v1.md) selects the exact Codex/Windows/game **qualification** tuple, while the customer-support result, exact customer sentences, connector manifest, package bytes, numeric limits and rights disposition remain open. A source tool name or a passing developer test cannot promote any row to customer support.

Every case must carry the applicable frozen identity envelope: signed installed artifact and companion hashes, CasimirBot account and enrolled client device, owner/node/source/subject/connector epoch, **selected local bootstrap pairing/action-authority/installation identity and reviewed installed-JAR→received-manifest→action-catalog mapping**, operation and manifest version, consent/authority/lease revisions, action or observation ID, and the typed result. Personal Codex MCP cases also record Codex client/profile/version; the [first-party hosted guest baseline](eh-g8-cfp1-hosted-guest-request-ingress-v1.md) records its own app/web route and explicitly proves the guest has no required Codex/GPT account. Optional guest-owned MCP cases record their separately supported client profile and tool-result re-entry. The [provisional five-row directory matrix](eh-g8-cfp1-public-directory-first-cohort-scope-v1.md) excludes Fabric sensor/player IDs from first-cohort public generic listing, pairing and active-device use; D12 must reconcile the final rows with qualified rights, while CFP-3 proves the server-side exclusion and old-device cutover. Neither selected local Fabric bootstrap sends a generic directory `package_version_id`. Redact one-time codes and reusable credentials. Use two clean ordinary-user profiles. Repeat the personal cases with a never-subscribed account and after a hosted term expires; hosted expiry must not remove independently authorized personal access. The [claim worksheet's evidence states](eh-g8-cfp1-first-customer-claim-freeze-worksheet-v1.md) apply separately to every subcase. Freeze thresholds and the expected native postcondition before execution; retain failed cohorts after repair.
