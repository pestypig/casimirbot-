# H2-P8F-C1 cloud-observable execution proposal

## Why this is a successor rather than a retry

The local P8F attempt was stopped without output and remains immutable partial
evidence. C1 has a new source, binary, image, archive, resource and output
identity. It therefore cannot overwrite or be represented as a retry of P8F.

C1 preserves the same panel count, coefficient, precision, threshold and
serial ordinal reduction. It changes the parallel batch width from 16 to 32
and adds a write-only callback after each completed batch. The executable
prints a progress record every 1,024 completed panels and at completion. Those
records cannot affect selection, accumulation or acceptance.

The candidate-neutral equivalence fixture compares the ordinary,
decomposition and observable paths byte-for-semantic-value at a bounded test
surface. It passed `17/17`, with zero candidate evaluations, positive samples,
roots, handler links or authority promotions.

## One-process execution and transport

The archive is uploaded once through the existing authenticated Cloud Shell
session and rehashed on the VM. The controller loads only the two pinned base
images, builds without pull or network, requires the executable hash, creates
one no-network read-only container with 32 CPUs and executes it once.

Stdout, stderr, progress, build identity, Docker inspect and chronology are
preserved. A deterministic evidence archive is hashed and base64-emitted to
the serial console before shutdown, avoiding a second rescue or SSH trust
workflow. The first build, identity, runtime or transport failure is terminal.

No candidate, proof, accepted geometry/state, SI, metric, lane or lamp
authority changes as a result of this run alone.
