# H2-P2 prepared-moment work packet

Status date: August 27, 2026.

## Frozen implementation boundary

The v1 bivariate and jet entrypoints remain callable as the numerical oracle.
The successor is additive:

1. A prepared object owns the same endpoint powers and all beta moments for one
   subpanel.
2. Preparation executes the existing 512-bit `fill_powers` and `beta_moment`
   loops once, in the original `(a,b,j)` order.
3. A separate bivariate entrypoint consumes those immutable moments while
   preserving all later multiplication, accumulation, centering and remainder
   operations.
4. A separate jet entrypoint prepares once and reuses the table for the frozen
   43 jet pairings.

The successor must continue to report 16,641 logical beta moments per
elementary convolution. Counters describe the frozen mathematical inventory,
not the number of physical cache constructions.

## Equivalence sequence

The implementation may advance only in this order:

1. Compile both entrypoints into one candidate-neutral fixture.
2. Compare acceptance, named failure detail and every result field.
3. Compare target geometry, retained order, all retained coefficients and all
   13 remainder bounds with `arb_equal`.
4. Exercise missing-output and invalid-inventory failure paths.
5. Build an uninstrumented successor calibration executable and compare its
   NDJSON with the frozen timing executable using the H2-P1 oracle.
6. Measure exponent zero locally. Cloud scaling is ineligible until all prior
   steps pass.

The first mismatch closes this attempt as evidence. It cannot be repaired by
changing the frozen arithmetic, excluding another output field or weakening
the equivalence relation.

## Cloud boundary

Google Compute Engine is available for a later bounded calibration. It will be
used only if the local exact-equivalence fixture passes and local timing shows
that the prepared path is genuinely faster. Any cloud run requires a separate
immutable input/image/command/output receipt and remains candidate-neutral.
It may not duplicate, stop or modify either preserved serial H2 execution.
