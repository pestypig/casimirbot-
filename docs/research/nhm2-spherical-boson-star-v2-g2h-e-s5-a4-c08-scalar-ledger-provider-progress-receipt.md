Initialization copies the four audited C08-006 origin models. Extension uses all
52 accepted endpoint balls to request the separately audited arbitrary-left
successor step and prepares all four new models before committing any of them.

shared faces.

views and tags without changing the prior publication used by C08-011c1 for
prefix serialization. Accepted model objects themselves never move. A finite
failure records its originating C08-006 through C08-009 code, publishes any
already accepted prefix once, and makes every later extension request return
the stored terminal decision without retry or retuning.

confirmed that the generic audited C08-010 selector exists, but no real H2,
P2, analytic-factor or dependent derivative-convolution ledger producer is yet
implemented. This scalar store is therefore not exposed as a successful
