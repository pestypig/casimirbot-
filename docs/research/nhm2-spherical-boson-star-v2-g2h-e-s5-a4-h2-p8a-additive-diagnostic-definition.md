## Frozen observation contract

For each width candidate actually evaluated, P8A records:

- candidate index and U-panel count;
- width pass/fail bit and exact check count;
- first failing term kind, coefficient degree and jet index;
- computed radius, permitted threshold and normalized radius/threshold ratio;
- the term with the largest directed-upper ratio and whether its ratio is
  certainly greater than one.

The radius, threshold and ratio are rendered at 80 decimal digits only after
the original Boolean width decision is complete. The diagnostic arithmetic is
not read by `replay_width_decisions`, candidate selection, failure precedence,
or `Result`/`Output` publication.

The ordinary four-argument `evaluate_prepared_parallel` call remains present
and calls the common implementation with a null diagnostic sink. The additive
five-argument named diagnostic entrypoint uses the same accumulation and width
decision, then writes the discarded observations. Null diagnostic ingress
fails closed.
